
# C++ Message Server

## 概要

C/C++を使用したメッセージ処理・タスクスケジューリングサーバーの個人開発プロジェクトです。

C/C++によるサーバー開発、ネットワーク通信、データ構造とアルゴリズム、Linuxコンテナ技術の習得を目的としています。

JSONとBinaryの相互変換、TCP通信、タスクの優先順位制御などの機能を段階的に実装していきます。

## 開発目的

- C/C++によるプログラミング能力の向上
- CMakeを使用したビルド環境の構築
- JSONとBinaryの相互変換処理の実装
- TCP/IPを利用したクライアント・サーバー通信の理解
- データ構造とアルゴリズムの実践
- GoogleTestによる単体テストの実装
- Podmanを利用したLinuxコンテナ環境での実行

## 使用技術

| 分類 | 技術 |
|------|------|
| プログラミング言語 | C / C++17 |
| ビルドシステム | CMake |
| 開発環境 | VS Code |
| テスト | GoogleTest（予定） |
| コンテナ | Podman（予定） |
| 通信 | TCP/IP（予定） |
| データ形式 | JSON / Binary（予定） |

## 実装予定機能

### 1. データ変換

- JSONからBinaryへの変換
- BinaryからJSONへの変換
- C言語の構造体を利用したデータ処理

### 2. メッセージ通信

- TCPサーバーの構築
- TCPクライアントの実装
- メッセージの送受信
- エラー処理

### 3. タスク管理

- タスクの登録・取得・削除
- キューによるタスク管理
- 優先度に基づくタスク処理
- タスクの実行状態管理

### 4. アルゴリズム

- キュー・ハッシュマップ
- 優先度付きキュー
- 二分探索
- グラフ探索（BFS / DFS）
- トポロジカルソート

### 5. テスト・運用

- GoogleTestによる単体テスト
- Podmanによるコンテナ化
- Linux環境でのビルド・実行
- パフォーマンス測定

## ビルド方法

### 必要環境

- C++17対応コンパイラ
- CMake 3.16以上

### ビルド

    cmake -S . -B build
    cmake --build build

### 実行

    ./build/json_binary_server

※ 現在は初期動作確認用のプログラムを実装しています。
